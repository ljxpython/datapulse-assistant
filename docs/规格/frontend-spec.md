# DataPulse Assistant —— 前端规格说明书 (docs/规格/frontend-spec.md)

> **版本**：v0.3.0 (已由用户拍板冻结)  
> **视觉设计基线**：**方案 A · Notion / Hex 交互式研报画布流 (The Clean Canvas)**  
> **技术栈**：React 18 + TypeScript + Vite + TailwindCSS + Lucide Icons + Apache ECharts / 优雅平滑 SVG  
> **核心哲学**：**“对话即研报，画布即交付”**。彻底摒弃死板左右分栏与深色大屏监控，采用麦肯锡商业研报级自上而下的清爽画布排版，打造呼吸感极强、高管友好的分析工作台。

---

## 二、色彩系统与排版标准 (Design Tokens)

彻底杜绝“煤老板死黑”与刺眼高饱和度荧光色，严格遵循瑞士国际主义平面排版：

| 属性 | 设计 Token | 视觉效果与说明 |
|---|---|---|
| **页面主底色** | `#FBFBFA` | 极柔和暖白象牙底，消灭纯白刺眼眩光，极度护眼 |
| **画布卡片底色** | `#FFFFFF` | 纯白卡片，配合 `border border-zinc-200 shadow-xs` 形成层次 |
| **主标题与数字** | `#18181B` (Zinc-900) | 深碳黑，高对比度，严谨有力 |
| **副标题与辅助** | `#71717A` (Zinc-500) | 柔和浅碳灰，拉开视觉阅读梯度 |
| **主强调色** | `#4F46E5` (Indigo-600) | 经典深邃靛蓝，用于图表曲线、主行动按钮与聚焦边框 |
| **成功/增长色** | `#059669` (Emerald-600) | 森林绿，用于正向环比增长与安全通过标记 |
| **预警/回撤色** | `#E11D48` (Rose-600) | 玫瑰红，用于负向跌幅与交付延期告警 |
| **数值排版** | `font-mono tabular-nums` | 所有金额、数量、百分比强制等宽，严禁跳动 |

## 三、组件功能契约与交互边界

### 1. SearchCapsule (居中提问胶囊岛)
- **外观**：`rounded-2xl border border-zinc-200 shadow-sm p-2 hover:border-zinc-300`，悬浮于画布上方；
- **交互**：
  - 支持回车或点击“开始分析”；
  - 附带 3~4 个预置快捷场景标签，点击后文字自动填入并触发打字机执行；
  - 执行过程中，输入框进入只读 loading 态，右侧按钮变为旋转指示器。

### 2. ExecutiveTrio (高管核心指标三元组)
- **结构**：3 列水平栅格，每个指标卡左侧带有深色小坚线指示（`border-l-2 border-zinc-900`）；
- **要素**：
  1. 指标名称（`text-xs text-zinc-500 font-medium`）；
  2. 核心大数字（`text-2xl font-bold font-mono text-zinc-900`）；
  3. 环比说明（`text-xs font-medium` 带有箭头指示）。

### 3. PublicationChart (杂志级通透图表)
- **要求**：
  - 纯白底色，极淡横向虚线网格（`stroke="#F1F1F4" stroke-dasharray="2,2"`）；
  - 面积图采用优雅的贝塞尔曲线（Cubic Bézier），顶部为 2.5px 靛蓝实线，下方为透明度递减的淡蓝渐变阴影；
  - 关键节点带有实心白底蓝环圆点，并清晰标注数值与标签。

### 4. SqlAuditDrawer (SQL 审计优雅抽屉)
- **设计哲学**：**不把技术细节强行塞在用户脸上！**
- **交互**：
  - 在报告右上角放置一个低调优雅的 `[ 审查 SQL 逻辑 ]` 按钮；
  - 仅当分析师或技术人员点击时，以轻量 Modal 弹窗或侧边抽屉展开，展示格式化 SQL、`sqlglot` AST 安全校验标识以及执行毫秒数；
  - 提供一键复制 SQL 功能。

### 5. ReportExportAction (研报导出)
- **支持**：
  - 点击“导出研报”，一键生成排版工整的 Markdown 文本或触发浏览器打印为 PDF 格式；
  - 严格贯彻三权分立：点击“归档到本地知识库”时，弹出确认弹窗后方落盘物理文件。
