## 二、Refactoring UI 核心排版与审美准则 (提炼自 151 规则)

### 1. 建立受限的间距系统 (Constrained Spacing Scale)
- 严禁凭直觉手写 `margin: 13px` 等随意值；
- 严格遵循 Tailwind 的 4px 乘数系统：
  - 微间距：`gap-1` (4px), `gap-2` (8px) —— 用于标签图标与文本紧凑排列
  - 中间距：`p-4` (16px), `gap-4` (16px) —— 用于卡片内部内容排版
  - 大间距：`p-6` (24px), `gap-6` (24px) —— 用于页面大分栏与主要卡片间距

### 2. 用字重和颜色区分主次，而不是放大字号 (Weight & Color over Size)
- 错误示范：主标题 36px，副标题 28px，正文 20px（整个界面巨大臃肿像老人机）；
- 正确规范：
  - 核心数值：`text-2xl font-bold tracking-tight text-slate-100 font-mono tabular-nums`
  - 属性标签：`text-xs font-medium uppercase tracking-wider text-slate-400`
  - 辅助说明：`text-xs font-normal text-slate-500`

### 3. 等宽数字铁律 (Tabular Numbers)
- 任何代表数字、金额、百分比、时间戳的标签，必须附加 `font-mono tabular-nums`，确保每个数字字符占用相同宽度，杜绝数值跳动时的界面晃动。

### 4. 严禁刺眼的灰色实线边框
- 抛弃 `border border-gray-400`；
- 暗色模式下统一使用**半透明边缘微光**：
  ```css
  border: 1px solid rgba(51, 65, 85, 0.8); /* border-slate-700/80 */
  box-shadow: inset 0 0 0 1px rgba(255, 255, 255, 0.05); /* ring-1 ring-white/5 */
  ```

## 三、Tremor 数据可视化看板核心原则

### 1. KPI 跑分卡四元组结构
每个指标卡必须具备四个要素：
1. **指标名称与指示图标**（右上角）；
2. **核心业务数字**（居中超大等宽加粗）；
3. **环比/同比胶囊 Badge**（绿涨红跌或反转）；
4. **时间周期上下文**（说明这个数字是过去 7 天还是当月）。

### 2. 表格数据对齐三原则
- **文本（名称、描述、类别）**：一律**左对齐**；
- **数值（金额、数量、百分比、耗时）**：一律**右对齐**（方便人眼垂直对比位数）；
- **状态（标签、操作按钮、开关）**：一律**居中对齐**。

## 四、组件四态同构门禁 (Ant Design Pro / Semi 容错)

编写任何数据驱动的 UI 组件（无论是 ECharts 容器还是数据表格），必须同时提供以下四态代码：

```tsx
export function MetricChartCard({ state, data, error, onRetry }) {
  // 1. Loading 态：骨架屏
  if (state === 'LOADING') {
    return <SkeletonChartCard />;
  }

  // 2. Error 态：原地优雅降级与一键重试
  if (state === 'ERROR') {
    return <ErrorAlertBanner error={error} onRetry={onRetry} />;
  }

  // 3. Empty 态：0 行数据友好提示
  if (state === 'SUCCESS' && (!data || data.length === 0)) {
    return <EmptyDataPlaceholder hint="当前时间段未产生销售记录，请调整筛选条件" />;
  }

  // 4. Success 态：标准渲染
  return <EChartsContainer option={generateChartOption(data)} />;
}
```

## 五、产品对外落地页与品牌门面设计规范 (源自 landing-page-design 技能)

> **集成位置**：[`.agents/skills/landing-page-design/SKILL.md`](../.agents/skills/landing-page-design/SKILL.md)  
> **核心用途**：用于 DataPulse Assistant 的对外展示门户、Demo 体验引导页与获客展示，让项目具备吸引投资人、技术同行与潜在用户的顶级商业视觉质感。

### 1. 结构化获客架构 (Part A: Strategy)
页面必须按照严格的 6 步说服链条展开，严禁一上来就堆砌技术参数：
1. **Above the fold (首屏黄金区)**：
   - **清晰 Outcome 标题**：“自然语言 ➔ 毫秒级只读 SQL 与交互看板，彻底解放数据分析师”
   - **具体 Subheadline**：明确技术栈与安全沙箱底线，说明为谁服务
   - **Primary CTA**：“立即挂载数据体验 Demo”
   - **社交与背书证明**：展示分析响应耗时 `< 800ms`、AST 安全拦截率 `100%`、开源 Star 徽章
   - **Hero 视觉**：真实的 DataPulse 高清运行界面与交互走势图动效
2. **Mid page (核心论据区)**：
   - **问题 ➔ 解法**：对比传统手写 SQL 的繁琐与 AI 盲写导致删库跑路的风险，突显“三权分立与只读沙箱”的不可替代性
   - **核心三步法**：上传数据源 ➔ 提出业务问题 ➔ 交互式看板与报告一键导出
3. **Bottom (打消疑虑与收尾)**：
   - **FAQ 专栏**：解答最关心的 6 个问题（数据会泄露吗？大模型会删库吗？支持大文件吗？）
   - **Final CTA**：与顶部呼应的启动按钮

### 2. 严苛视觉系统约束 (Part B: Visual System)
- **字体规范**：推荐使用 `Geist` / `Manrope`，代码与数值使用 `Geist Mono`；严禁使用常规斜体；
- **嵌套圆角黄金公式**：当子元素位于父卡片内且间隙小于 32px 时，强制执行：
  $$\text{inner\_radius} = \text{outer\_radius} - \text{gap}$$
  例如：外层卡片 `rounded-2xl` (16px)，内边距为 8px 时，内部元素必须是 `rounded-lg` (8px)；
- **自然物理缓动曲线**：禁止使用浏览器默认线性动效，统一采用减速曲线：
  `ease-[cubic-bezier(0.22,1,0.36,1)]` 配合 `duration-500`；
- **浮动磨砂导航栏 (Floating Translucent Bar)**：顶部导航栏悬浮居中，半透明背景配合 `backdrop-blur-md`；
- **严禁虚假 AI 废话**：文案中坚决禁止出现 "revolutionize"、"supercharge"、"cutting edge" 等无意义浮夸词汇，只用可测量的确定性数字说话。
